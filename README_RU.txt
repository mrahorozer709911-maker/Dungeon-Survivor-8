DUNGEON SURVIVOR 8.0 — ANDROID EDITION

В проекте:
- Улучшенные пиксельные эффекты: пыль, мерцание факелов, виньетка, вспышки попаданий.
- Анимации ходьбы персонажа, отдачи оружия, дульной вспышки, рывка и получения урона.
- Анимация врагов, монет и частиц.
- Android WebView-оболочка в полноэкранном портретном режиме.
- Игровой HTML находится в app/src/main/assets/index.html и работает офлайн.

Как собрать APK:
1. Открой папку проекта в Android Studio (Giraffe или новее).
2. Дождись синхронизации Gradle.
3. Установи Android SDK Platform 35 и подходящую версию Android Build Tools.
4. Выбери Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Ограничение среды: в текущей среде отсутствует Android SDK и Gradle, поэтому готовый APK здесь не был скомпилирован. Архив содержит Android Studio project для сборки APK; это не готовый APK-файл.
