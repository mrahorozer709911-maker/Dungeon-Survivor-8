DUNGEON SURVIVOR 8.0 — СБОРКА APK БЕЗ КОМПЬЮТЕРА

В архив добавлен GitHub Actions workflow: .github/workflows/build.yml.
Он собирает debug APK в облаке GitHub и прикрепляет APK как Artifact.

Сборка выполняется в облаке; компьютер не нужен. Открой вкладку Actions в репозитории, выбери “Build DUNGEON SURVIVOR APK” и нажми Run workflow, если автоматическая сборка не запустилась. После зелёной галочки открой запуск и скачай DUNGEON-SURVIVOR-8.0-APK в разделе Artifacts.

Это debug APK для тестирования, не подписанный релиз для Google Play. Не публикуй пароли или токены в репозитории.
